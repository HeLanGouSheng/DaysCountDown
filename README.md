# ⏳ DaysCountdown

A clean, lightweight Windows desktop countdown widget built with **.NET 8** and **WPF**.

[English](README.md) | [简体中文](README_ZH.md)

---

## ✨ Features

* 📌 **Desktop Floating Card**: Frameless minimal design, supports always-on-top mode and smooth dragging anywhere on your screen.
* 🎨 **Independent Transparency**: Separately adjust background and text opacity to perfectly match any wallpaper.
* 📆 **Smart Dual Countdowns**: Automatically calculates total days and **remaining workdays**.
* 🌐 **Multi-Language Support**: Built-in **English** & **简体中文** with instant, seamless switching (no restart required).
* 📌 **System Tray Integration**: Quietly runs in the background with quick right-click options and tray minimize support.
* 💾 **Local Persistence**: Automatically saves your events, language preference, and UI settings locally.

## 🚀 Quick Start / Download

1. Go to the [Releases](https://github.com/HeLanGouSheng/DaysCountdown/releases) page.
2. Download the latest `DaysCountdown_v1.0.0_win-x64.zip`.
3. Extract the ZIP file and run `CountdownDay.exe` directly (Portable & Self-contained, no prior .NET runtime installation needed).
