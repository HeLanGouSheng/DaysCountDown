# ⏳ DaysCountdown (倒数日悬浮挂件)

一个轻量、优雅的 Windows 桌面倒数日悬浮挂件，基于 **.NET 8** 和 **WPF** 开发。

## ✨ 核心功能

* 📌 **桌面悬浮卡片**：无边框简约设计，支持窗口置顶或随桌面自由拖拽。
* 🎨 **透明度独立调节**：背景与文字透明度可分别调整，完美融合各种桌面壁纸。
* 📆 **智能双重倒计时**：自动计算总剩余天数与**工作日剩余天数**。
* 🌐 **多语言支持**：内置 **简体中文** 与 **English**，支持即时无缝切换（无需重启软件）。
* 📌 **系统托盘常驻**：支持右下角托盘常驻、窗口唤醒以及右键快捷菜单。
* 💾 **本地持久化存储**：事件数据、透明度配置及语言偏好实时本地保存。

## 🚀 快速开始 / 下载使用

1. 前往 [Releases](https://github.com/HeLanGouSheng/DaysCountdown/releases) 页面。
2. 下载最新的 `DaysCountdown_v1.0.0_win-x64.zip` 包。
3. 解压后直接运行 `CountdownDay.exe` 即可使用（免安装绿色版，无需预装 .NET 运行时）。
